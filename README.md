# レーシングマスター コース出現統計 PWA

## 公開手順（GitHub Pages）
1. GitHubにログインし、新しい **Public** リポジトリ（例: `rm-course-tracker`）を作成。
2. このZIPを解凍。`index.html`、`manifest.webmanifest`、`sw.js` と `icons` フォルダを、リポジトリの**最上位**にまとめてアップロードしコミット。
3. GitHubのリポジトリで **Settings → Pages → Build and deployment** の Source を **Deploy from a branch** に設定し、Branch は `main` / `/(root)` にして保存。
4. 表示された公開URL（通常 `https://ユーザー名.github.io/rm-course-tracker/`）に iPhone の Safari でアクセス。
5. 共有メニューから **ホーム画面に追加** を選び、**Webアプリとして開く** をオンにして追加。

## 重要
- ZIPをiPhoneで直接開くだけでは、Service Workerは正常に有効化されません。HTTPS公開が必要です。
- 一度オンラインで起動してキャッシュが完了すると、基本画面をオフラインでも表示できます。ただしiOSのデータ削除等でキャッシュが消える可能性があります。
- 記録は利用端末のブラウザ保存領域に置かれ、サーバーに送信しません。Safariとホーム画面アプリで記録が共有される保証はありません。開始後はホーム画面アプリで記録してください。
- 旧版HTMLの記録は自動移行されません。旧版の「管理」→「JSON保存」、PWAで「JSON読込」を実行してください。
- データ損失に備え、定期的に「管理」→「JSON保存」でバックアップしてください。
- GitHub PagesをPublicで使う場合、**アプリのソースとコース候補は公開**されますが、ローカルに保存した個人のレース記録は公開されません。
- コース初期マスタは提供いただいた **20地域・107コース** に更新済みです。「管理」から追加もできます。
- 以前のバージョンの記録は可能な範囲で移行し、記録がある旧コースは残します。初回更新前にJSONバックアップを推奨します。
- PWAはゲーム本体と連携せず、ゲーム通信や画面を取得しません。

## v3: 新地域の追加
「管理」→「コースを追加」から、既存の地域なら選択するだけ。新地域なら「新しい地域名」に入力し、エリア分類を選んでコース名を入力して追加します。登録した地域は以降の地域選択肢に表示されます。

## 既存の公開PWAを更新する方法
1. **更新前にiPhoneのホーム画面アプリで「管理」→「JSON保存」**を行ってください。
2. 解凍したZIPに含まれる `index.html`、`sw.js`、`manifest.webmanifest`、`icons/` などを、**現在使用している同一のGitHubリポジトリ**の同じ場所に上書きしてCommitします。新しいリポジトリに公開するとURLが変わり記録を自動で引き継げません。
3. GitHub Pagesの更新後、iPhoneのホーム画面アプリを完全に閉じて再起動してください。必要に応じて一度オンラインで読み込み直します。
4. 従来の `localStorage` キー `rm-track-log-v1` は変更していません。記録履歴およびカテゴリ別集計を維持します。ただし端末のサイトデータ消去、URL変更、ホーム画面アプリの削除・再追加では失われる可能性があります。
5. 古いJSONバックアップも読み込めます。JSON読込は現在の記録を**上書き**するため、普段の更新では使う必要はありません。
